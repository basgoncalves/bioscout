  Create custom_settings.py:

        session_folder = r"C:\path\to\P013"
        setup_files_folder = r"C:\path\to\setup"
        generic_model = r"C:\path\to\model.osim"
        markerset = r"C:\path\to\markers.xml"
        static_trial_name = "static_01"

  Run:
    python __main__.py -batch custom_settings.py
