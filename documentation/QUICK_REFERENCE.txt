LAUNCH THE APP
==============
From the app directory, run:
  python run.py

Or directly:
  python __main__.py

(Dependencies will be installed automatically on first run)


FILE LOCATIONS
==============
• Main executable:     __main__.py
• Launch script:       run.py (recommended)
• GUI code:            gui/main_window.py
• Configuration:       config/default_config.yaml
• Analysis engine:     core/analysis_runner.py
• Logs:               logs/ folder


6 MAIN TABS
===========
1. EMG Processing    - Filter, normalize, export EMG signals
2. Analysis         - Run trial or session-level analyses (MAIN TAB)
3. Batch           - Batch processing queue (beta)
4. Results         - View analysis results
5. Configuration   - Project settings
6. Logs            - Application logs


QUICK WORKFLOW: IK VALIDATION
=============================
1. Launch: python run.py
2. Click Browse → Select trial directory
3. Check "Reload Files" (see detected files)
4. Check box: "Inverse Kinematics"
5. Click "▶ Run Pipeline"
6. Monitor output log
7. Results saved to trial directory


QUICK WORKFLOW: FULL ANALYSIS
=============================
1. Launch: python run.py
2. Click Browse → Select trial directory
3. Select analysis steps:
   ☑ Inverse Kinematics
   ☑ Inverse Dynamics
   ☑ Static Optimization
4. Click "Save Settings" (optional - saves to XML)
5. Click "▶ Run Pipeline"
6. Watch progress bar and log


QUICK WORKFLOW: BATCH SESSION
=============================
1. Launch: python run.py
2. Click Browse → Select session directory (parent of trials)
3. Select "Entire Session" radio button
4. Select your analysis steps
5. Click "▶ Run Pipeline"
6. App processes all trial subdirectories automatically

SETTINGS MANAGEMENT
===================
Save Settings:     Green button - saves to trial_settings.xml
Edit Settings:     Opens in text editor
Load Config:       Automatic - loads trial_settings.xml if exists
Reload Files:      Updates input file detection


INPUT FILES DETECTED
====================
The app automatically finds:
  • *.c3d              (motion capture data)
  • *marker*.trc       (marker positions)
  • *emg*.mot          (EMG signals)
  • *grf*.mot          (ground reaction forces)
  • *.csv              (events)
  • *.osim             (OpenSim model - searches up 2 parent dirs)

TROUBLESHOOTING
===============
App won't start:
  → python test_gui_launch.py
  → Check logs/ folder for error details

No input files found:
  → Check file naming matches patterns
  → Use "Reload Files" button

Analysis is slow:
  → Normal! 10-30 mins per trial
  → Session analysis: multiply by # of trials

Settings won't save:
  → Check trial directory is writable
  → Ensure trial_directory/trial_settings.xml path exists
