# `bioscout.model.scale`

[← API index](index.md) · [source](https://github.com/basgoncalves/bioscout/blob/main/bioscout/model/scale/__init__.py)

Model scaling: measurements/ScaleTool helpers (``measurements``) and the  
GUI's ``ModelScaler`` wrapper (``model_scaler``). Backs ``bioscout model scale``.

Nothing is imported eagerly so ``import bioscout.model`` stays stdlib-only.
